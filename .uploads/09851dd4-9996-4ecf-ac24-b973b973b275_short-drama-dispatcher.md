# 短剧Skill调度器（一条线路）

## 概述

本线路覆盖以下题材：
- 缅北/诈骗/犯罪
- 都市复仇/豪门/霸总
- 重生/穿越
- 古装权谋
- 恐怖/惊悚/密室
- 悬疑/推理
- 逆袭/爽文/打脸

> 后续会增加其他题材的独立线路，本调度器只负责当前这条线路的内部派发。

## 调度逻辑

根据用户输入判断调用哪个执行skill：

```
┌─ 用户有「故事文本」+ 无「大纲」+ 无「额外要求」
│   ├─ 用户明确要「大纲」→ skill_view("short-drama-half-outline")
│   ├─ 用户明确要「剧本」→ skill_view("short-drama-full-script")
│   └─ 用户没说明 → 追问："要半套大纲还是直接出分镜剧本？"
│
├─ 用户有「指定集数」+ 有「某集剧本」+ 无「故事」
│   └─ → skill_view("short-drama-edit-episode")
│
└─ 缺素材无法判断
    └─ 追问："请提供故事文本，或指定要修改的集数+剧本内容"
```

## 输出原则

只判断和调度，不做创作。追问时简洁给选项。
