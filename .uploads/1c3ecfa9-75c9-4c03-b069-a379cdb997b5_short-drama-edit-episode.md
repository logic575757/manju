# 单集剧本审核修改

## 概述

审核用户提供的某集短剧剧本（JSON格式），内部自动完成所有检查、修改、优化后，只输出修改完成的最终JSON剧本。不返回修改标注、问题清单——只返回可直接入库和前端渲染的成品。

## 适用题材

- 缅北/诈骗/犯罪
- 都市复仇/豪门/霸总
- 重生/穿越
- 古装权谋
- 恐怖/惊悚/密室
- 悬疑/推理
- 逆袭/爽文/打脸

## 内部审核维度（用户不可见）

### 一、黄金钩子检查

| 检查项 | 标准 | 不合格处理 |
|--------|------|-----------|
| 前2s画面 | 一人脸+一情绪+一威胁信号 | 重写visual字段，视觉冲击替代信息堆砌 |
| 前5s信息 | 观众能回答"谁/在哪/处于什么危险" | 补充关键信息 |
| 集尾钩子 | 最后一个B必须有悬念 | 改写最后一个B的画面/情绪 |

### 二、节奏与时长检查

| 检查项 | 标准 | 不合格处理 |
|--------|------|-----------|
| 总duration | 85-95秒 | 增减B的duration值 |
| 情绪变化 | 不连续30秒同情绪 | 调整emotion字段 |
| 台词密度 | dialogue单条≤20字，全集合计≤150字 | 压缩dialogue |

### 三、视觉冲击力检查

| 检查项 | 标准 | 不合格处理 |
|--------|------|-----------|
| shot_type分布 | 特写+近景≥50%，中景≥30%，全景+远景≤20% | 调整shot_type |
| 身体局部特写 | 至少2处 | 在紧张段落插入 |
| 性暗示 | 至少2处 | 插入锁骨/大腿/吊带相关visual |

### 四、风控排查

| 风控项 | 处理方式 |
|--------|---------|
| 枪支画面 | visual中删除枪支描写，sound中加画外枪声 |
| 血腥画面 | visual中只保留后果，删除伤口特写 |
| 全裸/性行为 | visual中改为局部+画外音暗示 |
| 过度暴力 | 保留打斗action，删除骨折/脏器描写 |

### 五、原意保留

修改时保留用户原剧本的：
- 核心剧情走向和人物动机
- 原有人设和说话风格
- 关键dialogue和标志性台词
- 用户特意设计的特殊镜头

## 输出格式（JSON）

与输入同格式（`short-drama-full-script` JSON schema）：

```json
{
  "episode": 1,
  "title": "...",
  "theme": "...",
  "duration": 90,
  "storyboard_blocks": [
    {
      "sb": "SB1",
      "scene": "...",
      "location": "...",
      "summary": "...",
      "shots": [
        {
          "c": "C1",
          "shot_type": "...",
          "composition": "...",
          "camera_movement": "...",
          "cut_reason": "...",
          "beats": [
            {
              "b": "B1",
              "type": "lip",
              "dialogue_tag": "",
              "duration": 5,
              "location_detail": "...",
              "visual": "...",
              "characters": ["..."],
              "action": "...",
              "dialogue": "...",

              "sound": "..."

    }

```

## 关键原则

1. **只输出JSON**：不说明改了什么、为什么改
2. **保持结构**：不改动原有SB/C/B编号体系，只调整字段内容
3. **补齐缺失**：输入缺字段则补齐（空字符串或空数组）
4. **可直接入库**：输出的JSON可直接POST到API
